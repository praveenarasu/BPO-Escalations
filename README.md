# BPO-Escalations

Deployable knowledge source for the BPO-Escalations Excel-analysis agent.

After GitHub Pages is enabled and the `Deploy knowledge base` workflow has
completed, the website URL is:

https://praveenarasu.github.io/BPO-Escalations/

The browser-readable knowledge base is in `index.html`; the same rules are
available in structured form at `knowledge-base.json`.
